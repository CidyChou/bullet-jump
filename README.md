# Bullet Jump v3.8 Enemy & Boss

在 v3.7.6 的基础上增加怪物种类、Boss 阶段和 3000m 后的平台收窄曲线。

## 新增重装近战怪

- 橙红色厚甲怪物。
- 血量远高于普通远程怪。
- 不会发射子弹。
- 会在平台上巡逻并向英雄冲锋。
- 只有身体真正碰到英雄时才造成伤害。
- 出生仍遵守安全距离，不会贴脸刷新。

## Boss

### 5000m：时间守门者

- 中型 Boss。
- 普通怪暂时停止刷新。
- 使用瞄准散射和环形弹幕。
- 击败后继续攀登。

### 10000m：终焉时间巨兽

- 大型 Boss。
- 更厚的血量和更多弹幕组合。
- 必须击败后才会显示通关结算。

Boss 会跟随当前镜头战斗区域，不会被玩家向上跳跃甩出屏幕。

## 平台宽度

- 0–3000m：保持原有宽度。
- 3000m 后开始逐渐变窄。
- 10000m 时最窄平台仍不少于 132 个逻辑像素。
- 不会生成接近角色宽度的极端窄平台。

python3 -m http.server 8080
