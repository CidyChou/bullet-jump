# Bullet Jump v4.0 · 五座高峰

静态 ES-module Canvas 竖屏射击攀登游戏。自动弹跳、自动瞄准，五关战役；保留构筑卡牌、子弹时间与时间跳跃。无需 bundler、外部字体、图片或音频资源。

- 完整流程：标题 → 选关 → 游戏 / 卡牌 → 暂停 / 设置 → 胜负结算 → 重试 / 下一关。
- 浏览器存档：逐关解锁、最高星级、最佳高度 / 分数 / 通关时间、声音设置、新手提示；存储损坏或被禁用时可继续玩。
- 战斗反馈：短停顿、受击闪白、限幅震屏、粒子、伤害数字、击退、枪口火花、落地形变、合成音效。遵循系统减少动态效果设置。

## 本地运行

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

电脑：← → / A D 移动；空格子弹时间；↑ / W 时间跳跃；Esc / P 暂停；暂停或结算时 R 重试；X 可在平台边缘 100ms 内补跳。卡牌用左右键选择、空格 / Enter 确认；菜单支持 Tab / Enter。

手机：按住游戏画面左右拖动，另一根手指可同时点技能。子弹时间内可上下拖动。角色自动弹跳、自动射击，左右边界相通；坠出镜头或生命耗尽失败。

## 关卡与调参

全部关卡参数位于 `src/data/levels.js`：高度、时间目标、平台宽度 / 间隔 / 横向跨度、移动 / 碎裂比例、敌人密度 / 混合 / 强度、Boss、构筑节点。每关先缓后陡的二次曲线由 `difficultyAt()` 统一计算。

| 关卡 | 目标 | 中途 Boss | 峰顶 Boss / 特点 | 时间目标 | 构筑次数 |
|---|---:|---|---|---:|---:|
| 01 初升 | 1400m | — | 启程守卫：慢速三发扇形 | 2:10 | 3 |
| 02 加速 | 2300m | — | 双相追猎者：双发射口交叉火力 | 3:15 | 4 |
| 03 弹幕 | 3200m | — | 星环织弹者：旋转环弹与瞄准扇形 | 4:25 | 5 |
| 04 夹击 | 4600m | 2500m 隘口巡守 | 裂隙双翼：侧向夹击与环弹 | 6:00 | 7 |
| 05 终焉 | 5800m | 3100m 时序核心 | 终焉时间巨兽：三式轮换，40% 血量强化 | 7:30 | 9 |

1 星：通关。2 星：用时不超过关卡时间目标 **或** 剩余生命 ≥60%。3 星：两者同时达成。暂停、菜单与选卡不计时；战斗停顿与时间技能计时。星级不会降低，最佳记录只改善。

`src/config.js` 负责全局物理 / 技能参数；`src/ui/FlowUI.js` 负责菜单；`SaveSystem` 使用 `bullet-jump-save-v1`。存档是本地的，不跨设备，也不保存未完成关卡的现场。

## 验证

```bash
npm test
# 已安装 Playwright / Chromium 且静态服务器运行时：
node tools/browser_smoke.mjs http://127.0.0.1:8080
```

浏览器脚本支持 `PLAYWRIGHT_MODULE`、`CHROME_BIN` 和 `SMOKE_ARTIFACT_DIR`。覆盖桌面 / 手机菜单、启动、非空画布、键盘 / 多指触控、暂停计时、设置保存和错误收集，截图默认写到 `/tmp/bullet-jump-smoke`。Playwright 仅是可选开发工具，不是运行或发布依赖。

Node 测试包含存档容错、星级边界、关卡曲线、跳跃容错、Boss 预警、运行重置和五关确定性模拟。模拟关闭玩家受伤，用实际子弹击败 Boss，验证可达性与完整流程；不代表真人平衡测试。
