# Bullet Jump Canvas v3.7

基于 v3.6 的交互升级版。

## 新增
- 卡牌支持 A/D、左右键选择，空格/回车确认。
- 游戏开始、技能释放、结算重开均支持键盘。
- 时间跳跃改为蓄力、停顿、平滑起飞三段动画。
- 卡牌错峰 duang 入场，键盘焦点高亮。
- 选中卡牌后产生 duang 缩放与全屏光效。

## 键盘
- A/D 或 ←/→：左右移动
- Space：子弹时间
- ↑ 或 W：时间跳跃
- 卡牌界面：A/D 或 ←/→ 选择，Space/Enter 确认
- 开始：Space/Enter
- 结算：Space/Enter/R

## 运行
```bash
python3 -m http.server 8080
```


## v3.7.1 启动修复

- 修复新版 index.html 与旧版 HUD.js 混合缓存导致的 null.style 崩溃。
- 所有 ES Module 内部 import 均增加 v3.7.1 版本参数。
- HUD 更新改为 null-safe，不会因单个可选 UI 元素缺失而中断游戏循环。
- 修复 favicon 404。
- 保留 v3.7 的完整键盘操作、时间跳跃蓄力动画与卡牌 Duang 动效。


## v3.7.2 Render Loop Fix

- 修复 `bind()` 覆盖 `start()`，导致 Canvas 动画循环没有启动的问题。
- `start()` 现在只负责启动 requestAnimationFrame 渲染循环。
- `beginRun()` 只在用户点击或按键后开始游戏并解锁音频。
- AudioSystem 不再在用户操作前创建或恢复 AudioContext。
- 所有模块缓存版本更新为 v3.7.2。


## v3.7.3 Bullet Time Restore

- 子弹时间完整恢复到 v3.6 的表现与手感。
- 恢复紫色时间场、径向暗角、屏幕边缘时间流线。
- 恢复英雄周围的紫色时间残影环。
- 恢复敌方弹幕与我方子弹的拖尾视觉。
- 恢复子弹时间进入粒子反馈与结束时的摇杆回切。
- 时间跳跃蓄力动画、键盘操作、卡牌 Duang 和启动修复继续保留。


## v3.7.4 Hit Feedback

- 真正受伤时加入约 0.075 秒短打击停顿。
- 屏幕震动、红色边缘闪烁与轻微白闪。
- 英雄发生短促压缩、旋转、击退和受击描边。
- 增加伤害数字、扩散冲击环和粒子。
- 生命条与顶部 HUD 同步产生打击反馈。
- 护盾抵挡采用较轻的蓝色冲击反馈。
- 手机设备支持时触发短振动。
- 保留 v3.7.3 的子弹时间效果，不做任何修改。


## v3.7.5 Safe Enemy Spawn

- 敌人只会生成在英雄前方、上方约 2～3 个平台以外的位置。
- 前期最低安全距离更大，后期才逐渐缩短。
- 英雄刚落地后的 0.72 秒内禁止生成新敌人。
- 禁止在英雄刚踩的平台、脚下平台或附近已有敌人的平台生成。
- 生成平台优先选择英雄上方可见、但仍有反应时间的位置。
- 保留敌人出生后快速开火的设定。
- 保留 v3.7.4 的受击反馈和 v3.7.3 的子弹时间效果。


## v3.7.6 文案更新

- 首页标题改为“是男人就上10000层”。
- 操作提示改为“← / → 移动”。
- 实际操作仍同时支持 A / D 与 ← / →。
